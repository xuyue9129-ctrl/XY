# 全球朝晚霞预报

公开网址：<https://xuyue9129-ctrl.github.io/XY/>

纯静态网站，支持 ECMWF / ICON / GFS / GRAPES / 自动模型。页面上的品牌字样已移除；仓库名称与已有分享网址保留。

## 预测含义

**0–100 是偏保守的观赏指数，不是发生概率，也不是经过实况校准的准确率。** 中高云、总云量、本地低云、降水、雾、能见度、湿度与 CAMS 气溶胶共同影响结果。缺少关键云况或降水数据时不评分；能见度或气溶胶缺失时降低参考信心，指数最高为 49（小烧）。

避免高估的处理：

- 修正原梯形评分函数下降段的分母错误，防止云量在临界值附近跳分。
- 总云量偏少时限制中高云得分；分层云量与总云量矛盾时降低参考信心。
- 霾、低能见度与高湿度以乘法折减指数，不能被有利的中高云抵消。霾的影响使用 AOD，缺失时才使用 PM2.5，避免重复计算。
- 只在确实少云时保留晴空暮色评分，厚云不再被误当成晴空。
- 点击地点后，沿真实太阳方位在 50 km、150 km 及两侧各 15° 共四点核对云雨，最多下调 40%，并同步更新该地点显示。远处数据缺失不会加分。地图未点选地点是本地初筛，不能视作完整光路计算。
- 日出日落来自气象 API。内部统一 UTC 秒，展示使用地点的 IANA 时区；曙暮光参考时段按太阳高度 -6° 至 +2° 选取（事件前后两小时内）。云况采用逐小时数据插值，**不是分钟级预报**；降水采用对应时段末的累计小时值。
- 不跨缺测小时、不外推模型覆盖范围，不给无日出／日落的日期虚构事件。极地时段边界和地形仍有额外不确定性。
- 30 分钟缓存，并在当地跨日时失效。异步响应按请求代次隔离，防止切换模型、日期、地点后回填旧结果。
- 每批最多 10 个地点，优先当前选中地点；网络超时或服务端临时异常最多自动重试一次。限流时遵循 Retry-After（无有效值时等候一分钟），暂停后续批次。错误提示列出未加载地点数量和示例，区分超时、网络失败与限流；重试保留已缓存成功结果。

当前 ECMWF IFS 0.25° 和全球 ICON 的能见度可能全为 null；页面保持“—”，不再虚构 10 km。参考信心是依据时效、缺测、云况变化、光路核对情况的启发式等级，并非统计置信区间。

## 验证与限制

运行 `npm test` 或 `node --test tests/*.test.cjs`，无需安装依赖。测试覆盖评分边界、缺测、雾雨、气溶胶、UTC/夏令时/日期线、太阳方位、极地事件、光路重复修正、异步请求串线与跨日缓存。

2026-09-17 对五种模型、北京／纽约／悉尼／朗伊尔城四个地点完成实时接口检查。使用当时重新拉取的 ECMWF + CAMS 数据，北京当日朝霞本地指数为 13（难见）。这与用户反馈“今晨没有朝霞”方向一致；**这是单例回归检查，不能证明整体准确率提升，也不是对当时原始预报版本的严格回测**。

指数权重、阈值、光路采样距离与减分系数尚未用大样本观测拟合。保守策略会增加漏报；缺测上限会令部分模型系统性低于数据较全的模型。真实云的光学厚度、山体和建筑遮挡、卫星临近云演变尚未纳入。两天外只供趋势参考。

后续应积累带地点、事件时间、出报时间、原始模型快照的实况记录（无霞／弱霞／中烧／强霞），按时间与地点划分训练和测试集；重点统计“报中烧以上但实况无霞”的空报率，同时报告漏报率，再校准阈值。当前没有足够的独立标签，不能给出准确率百分比。
